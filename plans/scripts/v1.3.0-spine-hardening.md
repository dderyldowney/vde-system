# Plan: VDE 1.2.0 @system-spine Hardening

**Goal:** Ensure all USP hydration scripts include the core `@system-spine` tetrad (Zsh, Git, Docker).

## Analysis
- `vde-python` was missing `docker.io`, although `git` was present (likely from the base image).
- `grep` reveals that most `scripts/setup/*.zsh` files do not explicitly list `docker.io` or `git` in their package alloy.
- To ensure a "Sovereign Ecosystem", every Spoke must have `git` and `docker.io` to interact with the Hub and neighbors.

## Proposed Changes
Update all `scripts/setup/*.zsh` files to include `git` and `docker.io` in their package lists.

### Target Files:
- All files in `scripts/setup/*.zsh` that lack these packages.

## Execution Strategy
- Use a `generalist` sub-agent to perform batch updates to the `scripts/setup/*.zsh` files.
- Verify the updates by checking a subset of the files.
- Rebuild a representative VM to confirm hydration.

## Verification
- Run `grep` to confirm no files are missing `docker.io` or `git`.
- Rebuild `vde-go` and verify `docker ps` and `git --version` inside the container.
