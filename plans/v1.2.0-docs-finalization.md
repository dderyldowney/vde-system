# Documentation Finalization: v1.2.0 Baseline

## Background & Motivation
To cement the v1.2.0 (The Hardened Handshake) baseline, all legacy references to `bash` execution must be purged from the documentation generation pipeline. The VDE ecosystem is now strictly ZSH-ONLY.

## Scope & Impact
- `docs/user-guide-intros.yml`: Contains legacy ` ```bash ` markdown blocks and installation instructions for bash.
- `tests/scripts/generate_user_guide.py`: Hardcodes ` ```bash ` block generation.
- `USER_GUIDE.md`: Will be regenerated from the updated source files.

## Proposed Solution
1. Use `sed` to replace all instances of ` ```bash ` with ` ```zsh ` in `docs/user-guide-intros.yml` and `tests/scripts/generate_user_guide.py`.
2. Execute `python3 tests/scripts/generate_user_guide.py` to rebuild `USER_GUIDE.md`.
3. Commit the final documentation alignment.

## Implementation Steps
1. Execute `sed -i '' 's/```bash/```zsh/g' docs/user-guide-intros.yml tests/scripts/generate_user_guide.py`.
2. Execute `python3 tests/scripts/generate_user_guide.py`.
3. Execute `git add . && git commit -m "docs: Finalize ZSH semantic purity in User Guide pipeline" && git push origin main`.

## Verification
- `grep "```bash" USER_GUIDE.md` returns 0 results.
- `bin/vde-enforce-uap.zsh` passes.
