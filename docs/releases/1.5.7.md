## 🛡️ Core Highlights

1.5.7 is the first baseline since 1.5.6 (2026-09-29) and carries about 100 merged changes. They fall into five groups.

### Student-facing (Armor)
- **Configurable Projects directory** (#543, #545, #669): the Projects base is student-chosen, resolved by one safe resolver (#564), honoured by every mount (#566) and by the tracked composes. `vde set-projects-dir` re-points it safely across filesystems, running Spokes, interruption and a stale exported variable; per-Spoke locks are held for the whole move.
- **USB hardware access** (#526-#535): serial passthrough with stable per-port device names under `/dev/vde/by-port/`, Hub-side udev rules, and the new `embed` Spoke (Python, C, C++, Rust, LLVM).
- **Python on pyenv** (#548): `vde-python` installs the latest stable CPython through pyenv, zsh-native.
- **Build-cache hygiene** (#617): `vde clean`, and Docker's build cache is pruned after rebuild/create. `vde prune` is dry-run by default (#620).
- **`vde add` / `vde uninstall` repaired** (#534, #536): ten defects, plus the Proof of Life now executes the setup script it adds (#537).
- **CLI correctness** (#582-#590, #623): unknown commands exit 2 with diagnostics; stop/restart/remove report deliberate exit statuses; typed arguments forwarded to audit, check-tetrad, spine-check, heal and `rebuild`; the router's handlers live in `lib/vde-actions`.

### Security
- Spoke containers receive only the SSH key and dev password from the root `.env`, not the whole file (#666).
- Compose no longer auto-creates a root-owned agent socket directory (#616, #618).
- Vendor installers are bounded, checksum-verified where the vendor publishes one, and the only foreign-shell code is the governed allowlist in `docs/governance/bash-exceptions.md` (#594, #596, #598, #600, #607, #608, #611).
- Service build-arg secret stripped from the regenerated compose baseline; `nuke` relocation guarded outside VDE (#564).
- Maintenance scripts and the Tetrad gate resolve lib/data/docs from their own root, not the caller's directory (#661, #663).

### Governance (Forge)
- The Zsh shibboleth is enforced across every tracked zsh file with a shrink-only baseline, judged on committed bytes, with a deepening fetch for shallow CI checkouts (#604, #626, #647, #651).
- The Ghost Zone audit reports stray `plans/` directories and never deletes them (#643).
- The paired-update check compares against the base and can fail; unit suites are discovered, not hand-listed.
- Native Claude Code and Antigravity skills expose the `.gemini` procedures (#642, #633).
- The pre-push Proof of Life is skipped only when this exact clean tree already passed it within 30 minutes (#602).

### Test harness
- Git-fixture tests scrub inherited `GIT_*` variables (#656); template-drift guard (#531); salvaged parser and lock suites (#586).
