## What's new

### Your projects, your place
Choose where your projects live, once, at setup. Change your mind later with `vde set-projects-dir`: VDE moves your work safely across drives, refuses to pull the rug from Spokes that are running, stays safe if the move is interrupted, and ignores a stale exported setting. Every Spoke, template and mount honours your choice.

### Plug in a board. Start building.
Connect an Arduino or ESP32-class board and use it from inside your Spoke. Boards get stable device names that follow the physical USB port, so `/dev/vde/by-port/…` points at the same socket every time you plug in. The new **`embed`** Spoke brings Python, C, C++, Rust and the full LLVM toolchain together for embedded work.

### Python, current by default
The Python Spoke now installs the latest stable CPython through pyenv, so you start on a modern interpreter without hand-building one.

### A tidier Docker, automatically
`vde clean` clears Docker's build cache on demand, and VDE now prunes it after every successful rebuild and create, so builds stop quietly eating your disk. Separately, `vde prune`, which tidies repository files and has nothing to do with Docker's cache, now previews what it would delete before it deletes anything.

### Predictable, scriptable commands
Mistyped commands now say so and exit with a clear status. `stop`, `restart` and `remove` report meaningful exit codes. Typed arguments reach `audit`, `heal`, `rebuild` and the other commands exactly as you wrote them.

### Safer by default
- Spokes receive only the SSH key and dev password they need, not your whole `.env`.
- Compose refuses a missing SSH agent socket instead of creating a root-owned directory on your host.
- Vendor installers run with time limits, and checksum verification where the vendor makes one available.
- Maintenance scripts always work from their own install, never from whichever directory you happen to be in.

### Certified, every time
The Proof of Life contract exercises the full lifecycle on every release: 6 scenarios, 73 steps, all passing. The Rule Spine and Gospel audits are clean, and CodeQL and the security and privacy audits pass.

## Get VDE 1.5.7

```zsh
git clone -b stable https://github.com/dderyldowney/vde-system.git VDE
cd VDE
bin/vde path-of-the-foundling
```

**Already installed?** From your install directory, pull the branch your install is on (most installs are on `stable`):

```zsh
cd VDE        # wherever you cloned it
git pull --ff-only origin "$(git branch --show-current)"
```

Installs from before `vde upgrade` existed cannot run it yet: this one pull brings it, and from then on use `vde upgrade`. Then rebuild the base image and the Spokes you use. A plain `vde rebuild <spoke>` reuses your existing base image, so name `base` to refresh it first:

```zsh
vde rebuild base <spoke>              # re-forge vde-base, then the Spoke
vde rebuild --no-cache base <spoke>   # the same, from scratch
```

**Requirements:** the Unyielding Tetrad: zsh, git, docker and ssh.

## Known limits
Probe-level USB debugging (SWD/JTAG) for the `embed` Spoke is not in this release. It is waiting on hardware validation ([#539](https://github.com/dderyldowney/vde-system/issues/539)). A few maintenance items are tracked openly and ship in a later point release.
